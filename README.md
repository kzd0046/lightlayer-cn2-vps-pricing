## 10M、300M、1Gbps 换算成下载速度是多少

Mbps 是比特，MB/s 是字节，中间差 8 倍。10Mbps 的峰值下载是 1.25MB/s，20Mbps 是 2.5MB/s，100Mbps 是 12.5MB/s，300Mbps 是 37.5MB/s，1Gbps 是 125MB/s。这是理论峰值，实际速度还受路由、距离和晚高峰影响。

按这个换算，年付 $24.99 的 10M 优化款，拉一个 100MB 的文件要将近一分半，看 1080p 勉强，4K 会卡。它适合跑 SSH、轻量代理、定时脚本、小博客这类不吃带宽的活。要建站给人访问、要传素材，300Mbps 的 LITE 或 1Gbps 的 L 才是正常体验。

不限流量不等于不限速，这是年付款最容易看错的地方。10M 不限流量意味着速度上限锁在 1.25MB/s，一个月理论最多跑约 3.2TB，实际用不到这个数。反过来，带 1TB/月流量的 1Gbps 机型速度快但月流量有上限，跑超了要么限速要么买流量包。选哪种，看你是怕超量还是怕慢。
